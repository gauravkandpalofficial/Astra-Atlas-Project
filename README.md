# Astra Atlas: Progressive Frontend Development Project

This repository contains the progressive development of the Astra Atlas
space-exploration website across four weekly frontend development tasks.

## What each week contributes

- **Week 1 - Responsive Landing Page:** branded hero section, responsive layout, mission storytelling, CTA and footer.
- **Week 2 - Interactive UI Components:** accessible Mission Explorer tabs, keyboard controls and mission-details modal.
- **Week 3 - Accessibility and UX:** skip link, semantic landmarks, ARIA state, focus-visible styling, reduced-motion support and accessible form feedback.
- **Week 4 - Frontend Performance Optimization:** A performance-focused revision of the Astra Atlas space-exploration landing page from Week 3.


A performance-focused revision of the Astra Atlas space-exploration landing page from Week 3.

## Run locally

Open `index.html` in a current browser. No installation, server or external dependencies are required.

## Keyboard testing

1. Press `Tab` when the page opens to reveal the skip link.
2. Navigate to Mission Explorer tabs and use Left/Right arrows, Home or End to change missions.
3. Open a briefing and close it with Escape, its close button or the return button.
4. Use Tab to reach the email form and submit an invalid then valid email address to hear/see status feedback.
