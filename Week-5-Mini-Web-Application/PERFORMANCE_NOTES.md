# Week 5 Performance Notes

The final mini application intentionally uses a small static JSON dataset, native HTML controls and a CSS-based chart. JavaScript is deferred, there are no third-party runtime libraries, and the application avoids large image downloads. These choices keep the initial dependency footprint small while retaining the required interactivity.

For a formal Lighthouse/PageSpeed measurement, deploy the Week 5 folder through GitHub Pages and run the same Mobile and Desktop audits used during Week 4. Record the captured scores and Core Web Vitals in this document rather than inventing values.
